orcad_project - schematic
Put here the OrCAD Capture project: <schematic code>_SCH.opj and <schematic code>_SCH.DSN
(e.g. 31010015159_SCH.opj / .DSN), plus the net classes file <schematic code>.Net.Classes*.xlsx.
The schematic must have the variant ASSEMBLY.
make_sch_docs.bat: .BOM files into ..\bom, schematic PDF into ..\electrical_schematic,
report into ..\production. Close Capture before running it.
